# Career Application Agent

기업분석과 개인 경험을 근거로 자기소개서·지원서·면접 답변을 작성하는 통합 작업 저장소입니다.

## 저장소 역할

| 저장소 | 원본 책임 | 저장하는 내용 |
|---|---|---|
| `company_readme` | 기업 사실 | 기업·산업·경쟁사·직무 분석과 공식 출처 |
| `experience` | 개인 경험 사실 | 경험 원문, 최신 정정, 자소서 에피소드와 성과 범위 |
| `career-application-agent` | 결합 산출물 | 공고 요구사항, 근거 매핑, 지원서 초안·최종본 |

기업 사실이나 경험 원문을 이 저장소에 복제하지 않습니다. 지원서에 사용한 근거의 원본 경로를 남겨 세 저장소의 내용이 서로 어긋나지 않도록 합니다.

## 자동 라우팅

- `기업분석해줘`: `company_readme`의 기업분석 에이전트를 사용하고 결과도 그 저장소에 저장합니다.
- `내 경험과 연결해줘`: 기업·직무 분석을 확인한 뒤 `experience`에서 검증된 경험을 찾습니다.
- `자소서 써줘`: 두 저장소의 근거를 결합하고 결과를 이 저장소의 `applications/`에 저장합니다.
- `AI 티 안 나게 다듬어줘`: 사실을 고정한 뒤 `humanize-korean` 스킬로 문체만 다듬습니다.

상세 절차는 [지원서 작성 스킬](.agents/skills/application-writing/SKILL.md)에 정의되어 있습니다.

## 지원서 산출물 구조

```text
applications/
└── 기업명/
    └── YYYY-MM-DD_직무명/
        ├── 01_요청과_공고.md
        ├── 02_근거_매핑.md
        ├── 03_초안.md
        └── 04_최종본.md
```

문항 하나만 작업하는 경우에도 동일한 폴더 안에서 필요한 파일만 만듭니다. 사용자에게 전달하기 전 사실·수치·기여 범위와 출처 경로를 검증합니다.
