## 03 초안 점검

- [ ] 관심 계기가 실제 경험 또는 확인된 자료에 근거한다.
- [ ] 선택한 경험의 과거 자소서 활용 이력과 최신 정정을 확인했다.
- [ ] 에피소드를 STAR 흐름으로 전개했다.
- [ ] S와 T는 간결하고 A에 판단 기준·대안·선택 이유가 드러난다.
- [ ] R에는 확인된 결과만 쓰고 한계와 배운 점을 구분했다.
- [ ] 행동보다 판단 기준과 선택 이유가 드러난다.
- [ ] 본인 역할과 팀 결과를 구분했다.
- [ ] 실제 성과와 목표·제안·예상 효과를 구분했다.
- [ ] 회사·직무 연결이 기업분석 근거와 일치한다.
- [ ] 글자 수 제한을 지켰다.
